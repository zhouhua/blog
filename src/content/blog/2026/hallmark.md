## 什么是 hallmark

hallmark 不是配色包，也不是组件库。它是写给 coding agent 的设计 skill，把字体、颜色、布局、动效和交互收成一套规则，用来做出不像 AI 生成的页面。

默认行为是做页面。另外三个入口是 study、audit、redesign。读的输入不同，交回的结果不同，判断标准是同一套。

## 设计理念

做页面时先定宏观结构，再配主题，再补细节。主题从 21 个命名主题里选。最近用过的三种宏观结构不会再重复，避免不同需求落到同一套版式上。

八条规则贯穿所有主题，都不是可以关掉的设置。字体分成展示和正文，不能由同一个字体家族同时承担。颜色用 OKLCH，一个锚点色，强调色不超过画面的百分之五。间距用命名的刻度，以四的倍数递增。动效用指数缓出，每个动画都要有减少动效的替代。语气随主题变化，不用产品页默认的中性口吻。布局要有偏向，全部居中是一种破绽。层级分成展示、正文和标签。没有合适的元素，就不如不加。

agent 默认会做出的五种样子，规则里都有对应的改法。头图不要用紫到蓝或紫到粉的渐变配居中白字，改为一个锚点色、一个强调色。Inter、Roboto 或 Open Sans 不要同时当作展示字体和正文字体，至少用两款，不能是同一家族。标题、正文和按钮不要节节居中。功能区不要一律做成左上角放图标的圆角卡片。导航不要一律是左字标、中链接、右按钮、滚动吸顶。导航应能说明这是什么类型的站点，例如报纸刊头或终端命令栏。

## 基本用法

直接让 agent 做界面即可，不必先加命令。也可以显式调用。

做新页面时，它读取需求、项目里已有的颜色和字体，以及所用框架。先选宏观结构，再选主题，再补细节，交回一个能用的页面，并按上述反模式检查过。例如：「给独立播客平台做落地页。」

`study` 接收截图或网址。它读结构，不读像素，交回一张可以对照着做的结构记录。也可以要求把这套结构写成可带走的 `design.md`。它不辨认具体字体，不复制像素。

`audit` 对着已有页面，按反模式列出要改的地方，并排出优先级。只给诊断，不改文件。

`redesign` 保留内容和品牌，换掉结构：新的章节节奏、标题位置和组件语气。

安装：

```bash
npx skills add nutlope/hallmark
```

Claude Code、Cursor 和 Codex 会各自放到对应目录。之后直接让 agent 做界面，hallmark 会自己接上。
